# Drift check

Generated by `python scripts/drift_check.py`.

**The dataset has no time dimension, so real drift over time cannot be measured here.** This report runs the PSI check on real data (train vs test, and new vs existing customers) and on one simulated shift. In production the reference would be the training data and the current sample would be each new month of scored customers.

PSI uses 10 bins at the quantiles of the reference sample. Reading: below 0.1 stable, 0.1 to 0.25 moderate shift, above 0.25 significant shift. Predicted probabilities come from the deployed model, which was fitted on train plus validation, so the training split scores are in-sample.
